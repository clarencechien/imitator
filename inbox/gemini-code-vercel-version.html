架構備忘錄：容器執行階段與面版治理

彙整 Framework 13 行動端痛點分析、macOS 原生虛擬化（vz）設定指標、開源容器工具矩陣與特權存取治理策略。

01 / 端點與伺服架構解構

Topology
Linux 行動筆電痛點 (Framework 13)
  • 休眠待機漏電 (S2Idle)：現代 x86 核心休眠喚醒不可控，背包常態發熱耗電；擴充卡插槽存在暗電流。
  • 非整數縮放 (Fractional Scaling)：3:2 高解析螢幕在 125%/150% 縮放時，XWayland 與 Electron 模糊。
  • 系統維護摩擦力：日常遭遇觸控手勢、驅動衝突與 UI Bug，修復成本侵佔實際生產力。
標準化工程架構分配
  • Client 端 (MacBook)：接管視訊、顯示渲染、電源睡眠調控，實現 14–18 小時長效續航。
  • Headless 容器端：macOS 底層僅運行無 GUI 的 Linux 核心，隔絕一切桌面端驅動與縮放缺陷。
  • Server 端 (Home Lab)：Linux 回歸 24 小時通電伺服器與多節點叢集，回歸極致效能與專注運算。

02 / macOS 虛擬化與 Colima 核心最佳化

Hypervisor
虛擬化本質：容器依賴 Linux Kernel（cgroups / namespaces），macOS 是 XNU 核心，先天不支援原生 Linux 容器。透過 Apple 原生虛擬化框架可大幅降低損耗，無需安裝任何肥大的桌面 GUI。
terminal — colima optimize script bash 
colima start --cpu 4 --memory 8 --vm-type vz --mount-type virtiofs --vz-rosetta
--vm-type vz Apple Virtualization

直接呼叫 macOS 原生虛擬化 API 替代傳統 QEMU，CPU 指令耗損極低，待機 CPU 佔用趨近於 0%。

--mount-type virtiofs 共享記憶體檔案系統

消弭 macOS 與 Linux 虛擬機目錄映射的 I/O 延遲瓶頸，大幅加速原始碼掛載與專案編譯效能。

03 / 本地容器執行階段與工具矩陣

Matrix
方案 授權性質 資源佔用 (RAM / CPU) Rosetta 2 (x86) 架構特性與定位
OrbStack 商業授權 (個人免費) 極低 (動態釋放回收) 原生支援 原生 Swift 開發、介面極度流暢、支援 Linux VM，Mac 開發首選體驗。
Colima 100% 開源 (MIT) 低 (待機開銷極小) 支援 (--vz-rosetta) 純 CLI 驅動、零合規風險，結合 Apple vz 框架可達到頂級效能與長續航。
Podman Desktop 100% 開源 (Apache 2.0) 中等 支援 無 Daemon / Rootless 資安架構，可直接連接外掛 Colima Docker Socket。
Docker Desktop 商業授權 (大企業需訂閱) 偏高 (常駐輪詢耗電) 需手動啟用 官方生態與 Extension 市集最完整，但虛擬機資源開銷較大。

04 / 管理控制台：Dockge vs Portainer BE

Orchestration
評估指標 Dockge (Compose-Centric) Portainer BE (Take 3 Free)
資料架構 檔案即真理（直接讀寫硬碟 compose.yaml） 資料庫優先（Stack 狀態存於專用資料庫）
運行記憶體 極小 (~30–50 MB RAM，無負擔) 中等 (~150–300 MB RAM)
K8s / 叢集治理 不支援（僅提供單機與輕量 Agent） 完整支援（Workloads、Helm、PVC、多叢集納管）
免費授權規範 100% 開源無限制 (MIT) ≤3 節點免費商業授權，支援一般 Gmail 登記

05 / Dockge 企業級安全與 PAM 治理策略

Security
邊界反向代理 (Authentik / SSO)

對接企業內部 AD/LDAP，強制 SSO 與 MFA 認證。

  • 架構限制：Dockge 內部缺少多租戶權限矩陣，放行進入後全員皆擁有最高 Root 權限。
  • 適用場景：內部成員皆為核心 DevOps/Admin，僅需統一企業帳號與入口閘道防護。
開源特權存取管理 (OSS PAM / 堡壘機)

採用 JumpServer (GPLv3) 或 Teleport 實施零信任管控。

  • 核心理念：以「審批流程 (JIT) + 全程畫面錄影審計」彌補面板內部細部權限缺失。
  • 防護能力：工程師提單核准後開通臨時連線，Web 點擊與終端操作全程側錄稽核。
