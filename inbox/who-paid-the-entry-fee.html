Paul Millerd 在《無路之路》裡用一條式子，解釋人為什麼離不開現在的工作。這篇把式子當程式碼來除錯：對著他自己的帳、別人的訪談和三份研究，把真正在跑的函式寫回去，再換成台灣的參數。

行次 01 · 這個詞

無路之路，原本是一句安慰自己的話

「無路之路」這個詞來自詩人 David Whyte 的《The Three Marriages》。Millerd 離職後讀到，借來當書名。照他書裡的說法，這個詞一開始的用途很小，就是一句拿來告訴自己「會沒事」的口訣。

它的對照組叫「預設路徑」。Millerd 的定義是：想被看成一個成功的大人，就得依序完成的那一串決定和成就。念好學校，進好公司，一路往上升。

這本書的主張比書名聽起來小。它沒有替哪一種活法背書，只反對一件事：把預設路徑當成唯一的選項。Millerd 也沒有把自己寫成勇者，他形容那段日子是好幾年務實又安全的小實驗。

行次 02 · 兩條式子

2008 年的福特，2022 年的 Millerd

書裡有一條常被引用的式子，用來解釋人為什麼會待在一份不滿意的工作裡：

不確定的不適感＜確定的不適感＋應對機制

左邊是離開，右邊是留下。應對機制指的是讓日子過得下去的那些辦法，像是把特休排滿，或是再撐到下一次年終。

台灣的觀眾更早就看過同一種寫法。2008 年福特 New Mondeo 的電視廣告「找回真實的自己」分成工作篇和家庭篇，畫面上各打出一條算式。工作篇是這樣：

你 ＋ 壓力 － 身段 × 堅強 ÷ 任性 ＝ ？

家庭篇把項目換成包容、習慣、責任和自由。工作篇的主角是四十歲上下的主管，在眾人面前被老闆丟文件，忍了下來。接著他把車開出地下室，一路開到山裡和海邊。

當年評這支片的文案老師唐崇達寫到片中那張辭呈，說很多上班族心裡早就寫過又揉掉。他也點出一個問題，放空是暫時的，回來還是得面對現實。

兩條式子隔了十四年，都把處境寫成算術，開出來的解法不同。Millerd 的解法是離開。福特的解法是一台柴油房車。用 Millerd 自己的詞來說，那台車就是應對機制，而且標了價。

天平右邊的砝碼，有一顆是廣告放的。

還有一個差別。福特的家庭篇裡有「責任」和「自由」兩項，Millerd 的式子裡沒有任何一項和家人有關。他離職時還沒成家，女兒 2023 年才出生。

行次 03 · 讀原始碼

把書裡的式子寫成程式

def 該留下嗎(我):
    return 不確定的不適感(我) < 確定的不適感(我) + 應對機制(我)

寫成程式之後，問題比較好指出來。

  1. 符號反了。「＜」要讀成「比較不想選」才通。照數量大小去讀，會變成不適感小的那一邊沒人選。應對機制該是減項，這裡寫成加項。
  2. 沒有事件。這是一個隨時都在比大小的比較器。照它的寫法，人每天早上都在重算要不要離職。
  3. 沒有錢，也沒有家人。存款、月支出、要養的人，一個參數都沒有。
  4. 沒有回頭路。回得去的人和回不去的人，面對的是兩種不確定，式子裡分不出來。

式子說不通，不代表作者走錯。它是他走通之後才寫的摘要。要找真正在跑的東西，得去看執行紀錄。

行次 04 · 執行紀錄一

他自己的帳

Millerd 在 2017 年離開紐約一家高階獵才公司。前一份工作的年薪，各家訪談的說法在 20 萬到 25 萬美元之間。

先看觸發點。他念完 MBA 之後，因為健康問題請過一段無薪假。《經理人》的整理文還提到外公過世，讓他開始問自己為了什麼而活。離職前他也沒有閒著，一邊上班一邊接職涯教練的案子。

再看錢。離職前後的數字，他在電子報裡陸續交代過。排成存摺會是這樣：

行次摘要與存入者金額
01離職時的存款存入者 · 預設路徑上的自己5 萬美元
02履歷：GE、McKinsey、BCG、MIT 的 MBA存入者 · 預設路徑上的自己無價
03接案費率：自雇第一年曾單月進帳存入者 · 顧問業的行情2 萬美元

前兩筆是他在預設路徑上存下來的。他大學念的不是顧問業會去徵才的學校，申請 McKinsey 還先被拒絕過一次，所以這些算不上天生的優勢。只是它們確實要照著那條路走，才累積得出來。

第四筆最特別。2018 年他搬到台灣，隔年把生活費壓到每月約 1,000 美元。存款是美元，開銷換成台幣計價的生活，同一筆錢能撐的時間拉長成三倍。

無路之路的入場費，是預設路徑付的。

行次 05 · 執行紀錄二

別人的紀錄

只看一個人的帳，寫出來的還是他的故事。Millerd 以外的紀錄有三種。

走出去又回來的人

Tom Grundy 在銀行做了十三年，倦怠之後跟主管談到六個月的長假。假放到一半讀了《無路之路》，覺得六個月不夠，2021 年乾脆辭職。接下來他上課、考教練證照，直到存款用完，信用卡開始吃緊。他投了幾家銀行都沒上，後來是舊同事通知原本的職位出缺，才回到老東家。他說回去之後壓力小了，也睡得好了。這篇文章登在 Millerd 自己的電子報上，讀的時候要記得這一點。

軟體工程師 Nicole Tietz-Sokolskaya 在 2017 年寫過另一種回去。她接案一年，案源和收入都過得去，最後還是回去當全職。理由有四個：美國自雇者的醫療保險很貴，夫妻都自雇時銀行不愛放款，她想念團隊，還有她發現自己不想當老闆。

研究者訪談過的人

倫敦商學院的 Herminia Ibarra 研究過 39 個轉職個案。她的結論和一般職涯建議的順序相反：成功轉職的人是先做再想，「知道自己要什麼」是做了之後才有的結果。整個過程通常要好幾年。

Schabram、Bloom 和 DiDonna 訪談了 50 位放過長假的專業工作者，論文登在 Academy of Management Journal。其中一個發現是，因為倦怠才去休息的人，最不會回到原本的工作。

華盛頓大學的 Lee 和 Mitchell 從 1994 年起研究人為什麼離職。他們和 Holtom 用一千兩百多位離職者的資料指出，離職最直接的原因多半是一個事件，他們叫它 shock。不滿慢慢累積到滿出來的情況比較少。

Millerd 自己八年後的版本

2026 年 1 月，一位 25 歲的讀者寫信問他該不該辭職。他回的是一張檢查表：精力和興趣是在長還是在掉，這一步是一年的實驗還是不回頭，財務風險怎麼降，情緒上要付什麼，哪些關係會受影響。最後一項他問得很直接：「Can you get back to where you are now?」

六項裡面，書裡那條式子只碰到情緒那一項。被問到是不是運氣好，他不接「成功」這個詞，只說自己有好幾年是打平，對再撐兩三年有一點把握。

真正的函式，他後來自己寫出來了。它只是沒有被寫進那條式子。

行次 06 · 真正的函式

把跑過的東西寫回去

把兩份執行紀錄疊起來，跑的大概是這個：

def 遇到事件(我, 事件):                # [A]
    if not 事件.夠大:
        return "繼續上班"

    while True:
        小實驗 = 最便宜的下一步(我)      # [B]
        if 小實驗.成本 > 付得起(我):     # [C] [E]
            我.應對機制.append(買得到的安慰)  # [F]
            return "繼續上班"

        結果 = 做(小實驗)
        我.知道的事.append(結果)         # [B]

        if 結果.養得活 and 結果.還想要:
            return "留在新路上"
        if 跑道(我) <= 0:                # [D]
            return "回去上班" if 我.回得去 else "卡住"

def 跑道(我):                          # 單位：月
    return 我.存款 / (我.月支出 + 我.要養的人)

def 付得起(我):                        # [D]
    return 跑道(我) if 我.回得去 else 跑道(我) / 2
  • [A] 先有事件才開始算。出自 Lee、Mitchell 與 Holtom 的離職研究，Millerd 的健康問題和外公過世也對得上。
  • [B] 小實驗是兼差、長假、接案、搬到便宜的地方這類小動作，也就是試水溫。做了才知道，出自 Ibarra 的 39 個個案和 Millerd 自己的做法。
  • [C] 跑道等於存款除以支出。出自 Millerd 自己公開的數字。
  • [D] 回不回得去。出自 Millerd 2026 年的檢查表和 Tom Grundy 的經過。除以二是我隨手寫的，沒有根據，只表示要打折。
  • [E] 小實驗的成本包括放棄的東西，像年終、分紅、年資。
  • [F] 付不起小實驗時，人會去找買得到的安慰。Millerd 叫它應對機制，福特賣的是其中一種。

和書裡的式子比，差在三個地方。它由事件觸發，平常不會跑。它是一圈一圈的小動作，沒有縱身一跳那一行。每一圈開始前都要先過「付不付得起」這一關。

應對機制不在天平的哪一邊。它是付不起小實驗時走的那個分支。

手冊版：給不讀程式的人

同一個函式，照飛機維修手冊的寫法再寫一次。規則是短句，一步只做一件事，一個詞只有一個意思。每一步的答案是一個數字，或者是和否。

程序 · 發生一件事，讓你想離職

事
一件讓你認真想離職的事。
月數
存款除以每月開銷。開銷要算進你養的人。
小實驗
一個花得起、做得完的小動作。例：投一份履歷。兼一個案子。請一段長假。
退路
你能回到現在這種工作。

結束 紅燈，這張表到這裡為止下一步 綠燈，往下做

  1. □有沒有發生一件「事」？沒有：結束 這張表用不到。有：下一步
  2. □等兩個星期。你還在想這件事嗎？不想了：結束還在想：下一步
  3. □算月數，寫下來：＿＿ 個月。下一步
  4. □你有退路嗎？沒有退路，就把月數除以二。下一步
  5. □選一個最便宜的小實驗。下一步
  6. □算這個小實驗的成本，單位是月。會放棄的年終和分紅也要加進去。下一步
  7. □成本有沒有超過月數？超過：結束 這個小實驗不做，繼續上班。沒超過：下一步
  8. 繼續上班的時候，你會找辦法讓自己撐下去。有些辦法要花錢，花掉的錢會讓月數變少。
  9. □去做這個小實驗。下一步
  10. □做完寫下兩個答案：養得活自己嗎？還想要嗎？下一步
  11. □兩個答案都是「是」嗎？是：結束 留在新路上。不是：下一步
  12. □月數還有剩嗎？有：回到第 05 步沒有：下一步
  13. □月數用完了。你有退路嗎？有：結束 回去上班。沒有：結束 卡住。

「月數」就是程式裡的跑道。兩個星期和除以二是我定的，沒有根據。這種寫法叫 ASD-STE100，Andrej Karpathy 在 2026 年 10 月建議用它來要求 AI 寫出好檢查的答案。

拿六個案例來跑

第四列是失敗的測試。第一版的函式只檢查「養得活」，照它算，Nicole 應該留在新路上。她回去的理由裡，有兩個和錢無關：想念團隊，不想當老闆。這正是 Ibarra 說的，小實驗會告訴你原本不知道的事，包括「我其實不想要」。所以函式裡補了「還想要」這個條件。

補完之後，第二列也說得通了。2021 年的 Millerd 前一年只賺 4.5 萬美元，眼前有一份高薪工作，光看錢應該回去。他在另一場訪談裡說過，比起收入不穩，他更怕的是得回去找一份工作。

這張表不能當成驗證。六個案例是我挑的，函式是照著它們寫的，其中一列是廣告劇情，一列是假設。它能說的只有一件事：書裡的式子解釋不了第三列和第四列，這個函式可以。

要推翻它，得找到另一種人：沒有遇到什麼事件，跑道很短，回不去，卻直接跳出去而且過得不錯。這種人一定有，我沒有查到他們占多少。

行次 08 · 換參數

同一個函式，換成台灣的參數

先換幣別。以當年約 30 元的匯率粗算，Millerd 那一個月 2 萬美元的顧問收入大約是 60 萬台幣。主計總處公布的 113 年全年總薪資中位數是 54.6 萬。他一個月接案賺的，比台灣一半的受僱者一整年還多。他的 5 萬美元存款約 150 萬台幣，是這個中位數的 2.7 倍。

其他參數逐項查過，結果和我原本想的不太一樣。表裡的「成本」指做一次小實驗要放棄的東西：

參數台灣的值根據
存款薄68.75% 的受僱者領不到平均年薪。2024 年受僱人員報酬占 GDP 降到 43.1%，是歷年最低。
月支出房貸很重2026 年第一季全國房貸負擔率 41.46%，台北市房價所得比 14.72 倍。

成本：分紅股票有，限少數產業電子零組件業的年薪中位數是 87.6 萬，比整體高出六成。
成本：特休有，很輕換雇主後特休重新起算。

成本：健保零全民健保不跟著雇主走。Nicole 回去上班的第一個理由，在台灣不存在。這一項是一般知識，沒有另外查。
回得去不知道中年離開再回來的成功率，我沒有查到資料。

對照美國，台灣綁人的制度其實比較輕。退休金帶得走，看病不靠雇主。雇主放的砝碼，集中在發得出分紅的那幾個產業。

重的是前兩列。存款薄，房貸吃掉四成所得，算出來的跑道以月計。跑道短，付得起的小實驗就只剩最便宜的幾種：投履歷、兼一個案子、約人聊。大一點的像長假和搬家，多數人付不起。

台灣人並沒有因此不動。勞動部 2022 年的調查裡，三成多的青年勞工想換工作。只是換雇主仍然走在預設路徑上，Millerd 講的離開是離開受僱這件事。這一句是我的推論。

行次 09 · 知行 接回 知行筆記

入場費，就是「行」的價錢

知行筆記的〈行變便宜了，知還是貴的〉量過一件事：信念排在行的下游。Bandura 列的四個來源裡，最強的是親身做成過。別人的勸說和當下的情緒都比較弱。

拿這把尺來量《無路之路》。流傳的第二條式子，是在離開那一邊加上「好奇」，天平就翻過來。好奇是一種情緒，屬於比較弱的來源。那一篇對 Dan Koe 和 Felix Rieseberg 下過同樣的評語：力氣放在弱的來源上，讀起來有感，做起來撐不久。

Millerd 實際走的是強的那一條。先接一個案子，先搬去便宜的地方住一年，做完才知道自己要什麼。Ibarra 的個案也是這個順序。他的式子寫的是知，他的做法是行。

差別在價錢。那一篇說 agent 把「行」的價格打了下來。換到職涯上，行沒有變便宜，每一次小實驗都要拿跑道去付。

知要靠行來換，而行的報價，每個人拿到的不一樣。

行次 10 · 結存

除錯之後，帳上還剩什麼

  • 預設路徑不是唯一的選項。這個主張很小，也很難反駁。
  • 式子可以放下，函式可以留著：遇到事件，找最便宜的小實驗，先看付不付得起。
  • 應對機制不是意志薄弱。它是付不起小實驗時的分支，其中有些是別人賣給你的。

所以讀完這本書，值得拿來問自己的是三件很具體的事：我的月數是多少，我有沒有退路，我現在付得起的最便宜的小實驗是哪一個。

那他算不算倖存者

書是。它是自費出版，賣了超過 6.5 萬本，版稅累計約 32.5 萬美元。流傳的統計是九成自費出版的書一輩子賣不到 100 本。函式解釋不了書為什麼賣。

路不太算。出書前他已經走了五年，那五年寫作沒有直接帶來收入，靠的是開銷壓得夠低。離職這個決定更談不上，他最壞的結果是回去上班。

偏誤比較可能藏在他身邊的樣本裡。他寫過，很多自雇的人三到五年會回到原本的收入水準。經濟學家 Hamilton 用美國資料算過，自雇滿十年的人，收入中位數比同條件的受僱者低 35%，大約到前四分之一才反過來贏。Levine 和 Rubinstein 後來發現，有設公司的那一群自雇者時薪高於受僱者，而這群人年輕時的測驗成績本來就比較好。Millerd 的朋友比較像這一群。

這篇沒做到的，請自己去看

  • 我沒有讀完整本書。根據的是讀者劃線、作者的電子報和幾場訪談。
  • 加上「好奇」的第二條式子，我手上只有轉述，沒有對到原文。
  • 六個測試案例是我挑的。函式是事後擬合，沒有拿新的案例驗過。
  • 外公過世這件事出自《經理人》的整理文，那篇不是親訪。
  • 年薪有 20 萬和 25 萬美元兩種說法，都來自訪談或書籍文案。
  • Karpathy 那則貼文我讀的是別人的轉述。手冊版只借了它的寫法，中文沒有對應的核可字表。
  • 福特廣告的算式和劇情，根據的是 2008 到 2010 年的部落格紀錄，我沒有看到影片本身。
  • 匯率用當年約 30 元粗算。拿 2017 年的美元去比 113 年的台灣薪資，只能看量級。
  • 自費出版的銷量統計出自整理網站。「年後 20 萬人次」是人力銀行從職缺數推估的。
  • Hamilton 用的是美國的舊資料，台灣自雇者的情況我沒有查。
