知易行難 · 行易知難 · Agent

行變便宜了，
知還是貴的

《尚書》說知易行難，孫文說行易知難。一百年後，心理學把人身上這道落差量了出來，agent 又把「行」的價格打了下來。這篇讓同一個問題過六站，看瓶頸現在停在哪。

站 01 · 進料

兩句話，講的是兩道落差

「非知之艱，行之惟艱」出自《尚書・說命》，意思是知道不難，做到才難。孫文引用時寫成「知之非艱，行之惟艱」，日常的說法就是知易行難。

孫文把它倒過來。書名是《孫文學說——行易知難》，自序落款在民國七年（1918）十二月三十日，後來編進《建國方略》成為〈心理建設〉。現在通行的說法是知難行易，書裡用的卻一律是「行易知難」，我查的全文裡找不到知難行易這四個字。兩種說法意思相同。

前四章舉了十件事當證據，飲食、用錢、作文各佔一章，另外七件合成一章，論點是人類一向沒弄懂原理就先做了。第五章收尾時他說，有這十證，「知之非艱，行之惟艱」的古說和王陽明的知行合一「皆可從根本上而推翻之」。他給知行合一的評語是「不合於實踐之科學」。

他寫這本書有很實際的目的。辛亥之後建設計畫推不動，他在自序裡把病根指向知易行難這個觀念，說要「先作學說，以破此心理之大敵」。國父紀念館中山學術資料庫的介紹把這種心態叫「輕知怯行」。自序裡還有一句話，今天讀起來像心理學教科書：

吾心信其可行，則移山填海之難，終有成功之日；吾心信其不可行，則反掌折枝之易，亦無收效之期也。

兩句話看起來相反，其實各自講的「知」不一樣。

知易行難行易知難
「知」指什麼知道該做什麼懂得為什麼、怎麼做才對
落差在哪想做，卻沒做沒懂就不敢做，其實做了才會懂
心理學的名字意圖與行為的落差自我效能從哪裡來
在哪一站量站 02站 03
本站判定

兩句話可以同時成立，要分開量。

站 02 · 作業

人自己做的時候，卡在行

先量《尚書》那一半。社會心理學把「打算做」叫意圖，幾十年來一直在量意圖能預測多少行為。Sheeran 彙整過 422 篇研究，兩者的相關是 0.53。換成白話，他和 Webb 在 2016 年的回顧裡說，意圖大約只有一半會變成行動。

更直接的證據來自實驗。Webb 與 Sheeran 找了 47 個成功拉高意圖的實驗，意圖平均提升了 0.66 個標準差，行為只跟著動了 0.36。把人說服到想做，離做到還有一大段。

有兩樣工具被反覆驗證能補上這一段。

只拉高意圖

寫成「如果…我就…」

0.65

94 個檢驗，對目標達成

定期監測進度

0.40

138 篇研究，對目標達成

三個數字都是效果量 d，來自三份不同的後設分析，比較的基準不一樣，不能拿來排名。可以確定的是方向：把時間地點寫死，還有回頭看自己做得怎樣，這兩件事都有用。監測那份研究還發現，結果公開或實際寫下來的時候效果更強。

本站判定

《尚書》那半句成立。人自己動手時，瓶頸在行。

站 03 · 回流

信念和身分，是做出來的

再量孫文那一半。他說的「信其可行」，Bandura 在 1977 年給了名字叫自我效能，並列出四個來源：親身做成過、看到跟自己相似的人做到、別人說你可以、自己當下的身體與情緒狀態。四個裡面最強的是第一個。

後來的資料把因果方向看得更清楚。Sitzmann 與 Yeo 2013 年的後設分析追蹤同一個人前後的變化，把原本的趨勢控制住之後，過去表現對自我效能的影響仍然成立（ρ=.30），自我效能對之後表現的影響掉到不顯著（ρ=.06）。他們的結論是，自我效能主要是過去表現的產物。

先有做成的紀錄，才有相信自己的本錢。

身分也是同一個方向。自我成長文章常說先認定「我是這種人」，行為就會跟上。直接操弄身分的實驗裡最有名的一個，是 2011 年把問卷裡的「去投票」改成「當個投票者」，據稱能提高投票率。2016 年的重複實驗沒有重現，原作者回應說選舉不夠受矚目。後來有人挑 2016 年美國總統大選做預先註冊的重複實驗，還是沒有效果。

所以「先假裝自己是誰」要分兩種。寫一句宣言屬於口頭說服，力道有限。照那種人的做法去做一件事才有效，而那已經是行動了。習慣研究也給了耐心的理由，倫敦大學學院的追蹤發現，一個新行為平均要 66 天才變得自動，中間漏掉一次沒有明顯影響。

回頭看孫文，有一點值得玩味，這是我的讀法。他診斷的是國人不相信做得到，開的藥卻是寫一本書去說服大家。照 Bandura 的排序，這是比較弱的那種來源。

本站判定

孫文那半句也成立。信念排在行的下游。

站 04 · 委外

用 agent，是哪一種能動性

Dan Koe 那篇文章把能動性列為成功的三個成分之一，講的是自己動手的那種。Bandura 在 2001 年把能動性分成三種，agent 屬於第二種。

類型誰在做靠什麼信念
親自personal自己我做得到
委託proxy有資源、專長或影響力的別人我有辦法讓別人替我把事做成
集體collective一群人協調著做我們做得到

Bandura 說的委託，對象是手上有資源、專長或影響力的人。他列了人會把事情委託出去的三個理由：自己沒有手段、相信別人做得更好、或是不想扛直接控制帶來的負擔。他還特別提醒，人對掌控的需求沒有一般說的那麼普遍。

代價他也寫了兩條。第一，依賴別人會讓自己的能力停止發展。第二，安全感從此寄放在別人的能力、權力和好意上。同一篇文章也說，委託可以促進自我發展，也可以妨礙，看怎麼用。

把「別人」換成 agent，這幾段幾乎不用改。目前也有初步的資料。微軟研究院與卡內基美隆大學在 2025 年調查了 319 位知識工作者，收集 936 個實際使用生成式 AI 的例子。對 AI 越有信心的人，回報的批判思考越少。對自己越有信心的人，回報的批判思考越多。這是自陳問卷，只能說明相關。

本站判定

交給 agent 屬於委託。要練的信念換了一種，代價理論上早就寫好。

站 05 · 檢驗

瓶頸換站

Dan Koe 文章裡最實在的一段是控制迴圈：設目標、行動、量測、跟目標比較，再依結果修正。站 02 的數字說明，人自己跑這個迴圈時卡在行動。交給 agent 之後，行動那一站的成本掉下來，卡住的地方跟著移動。

下排不是推測。先前那次試飛讓 Claude Code 做三題單檔 Three.js，總共 15 次迭代、0 次人工介入、50 分鐘、約 15 萬 token，三題的 console error 都是 0。也就是說「跑」從頭到尾沒出過問題。15 次迭代全部花在自動裁判看不見的地方，像是畫面錯、數字錯，為了看見這些還另外寫了大約 250 行探針。

這跟站 02 的監測研究是同一件事的兩面。人自己做的時候，回頭看進度能提升達成率，寫下來效果更好。交給 agent 之後，「看」從加分項變成整條線的產能上限。

孫文的行易知難，在這裡變成字面上的意思。他把人類進化分成三期，拿來對照今天交辦 agent 的三種做法，意外地貼。這是類比，不代表他預見了什麼。

孫文的三期交辦 agent 的做法知在哪裡
不知而行由草昧進文明丟一句話就讓它跑沒有。跑完也不知道對不對
行而後知由文明再進文明跑完看結果，把失敗記下來再改在失敗清單裡
知而後行科學發明而後先寫清楚怎樣算對，再讓它跑在規格與檢驗裡

他還把人分成三種，先知先覺的「創造發明」，後知後覺的「倣效推行」，不知不覺的「竭力樂成」。書裡第七章的章名就叫〈不知亦能行〉。照這個分工，agent 接走的是竭力樂成那一段，留給人的是前面兩段。

本站判定

行交出去之後，瓶頸從作業站移到檢驗站。

站 06 · 出貨

野心接在哪裡

Felix Rieseberg 那篇〈How to be more ambitious〉談的野心，用的詞就是自我效能。試飛篇已經對過一次帳：他舉的三個例子，對應到四個來源裡的三個，漏掉最強的親身做成過。

拿同一把尺量 Dan Koe 的一天流程，結果很像。

Bandura 的來源Felix 的例子Dan Koe 的流程
別人說你可以Dantzig 把未解難題當成作業寫給自己的身分宣言
看到相似的人做到Bannister 破四分鐘之後有人跟進「誰已經活在你害怕的未來」那一題，用的是反面示範
身體與情緒狀態《網球內心遊戲》反願景，整個早上都在調動情緒
親身做成過沒有只有晚上最後一題，排明天的兩三件事

兩篇都把力氣放在比較弱的來源上，這也解釋了為什麼它們讀起來很有感，做起來卻撐不久。照 Bandura 的理論，效能感高的人會挑更難的目標，所以野心是效能感的下游，效能感又是做成紀錄的下游。

接上站 04 和站 05，用 agent 之後要累積的做成紀錄換了內容。以前是「我寫得出來」，現在是「我交代得清楚、給得出條件、驗得出對錯」。少了這種紀錄，野心照樣可以很大，試飛篇對那種狀況的描述是：沒有感知的野心，長出來的全是裝飾。

帶得走的三件事

  1. 自己的事，先做一件小的。把時間地點寫死，做完留下紀錄。「我是哪種人」等紀錄累積了再說。
  2. 交出去的事，先寫怎樣算對。能交給機器檢查的交給機器，檢查不到的列成清單自己看。每一輪的失敗都記下來，那份清單比成品值錢。
  3. 留一塊自己動手。委託的代價是能力停止發展。哪一塊要保持親手做，自己先選好，別等它悄悄不見。這一條是我從 Bandura 的理論和那份問卷推出來的，目前沒有實驗直接支持。
出貨判定

野心的本錢，是一筆一筆驗得出來的紀錄。

這張卡的限制

站 02 的效果量來自不同的後設分析，各自的比較對象不同。站 03 的自我效能研究看的是同一個人前後的變化，不能直接推到人與人之間的差異。站 04 的問卷是自陳資料。站 05 的試飛是一個人做的一次實驗，樣本很小。孫文的部分是類比。原文句子對的是網路上的全文轉載和黃自進的論文，那份轉載有排版錯字，沒有對過紙本。
