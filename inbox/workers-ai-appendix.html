Pocket Polis 為了保護一份選配的 AI 摘要，寫了一整套 UTC 日級的預算帳本。這篇把那個帳本背後的計價、目錄與限制攤開：目前有哪些模型可以選、免費方案到底能跑幾次、以及為什麼那套帳本讓自己少了三倍餘裕。

這是《62% 同意，是兩個答案》的番外。價目與限制引自 Cloudflare 官方文件（定價頁 2026-08-28 更新、限制頁 2026-08-07 更新），目錄變動很快，數字請以官方頁面為準。

01 · 計價

neuron 不是模型，是計價單位

先修一個常見誤解：neuron 跟 PCA、k-means 無關，它是 Workers AI 把所有模型的 GPU 成本統一換算後的單位——文字算 token、圖片算 tile 與 step、語音算分鐘，最後都折成同一個數字。

規則很短：每 1,000 neurons 收 US$0.011；每個帳號每天免費 10,000 neurons；每日 00:00 UTC 重置，超過任一上限之後該類操作直接報錯。免費與付費方案的每日免費額度是一樣的 10,000 顆，付費方案只是允許你超過它。

關鍵字是「報錯」，不是「降速」。額度用完之後 ai.run 直接失敗，而且要等到下一個 UTC 日。這就是為什麼 Pocket Polis 要在呼叫模型前先做原子預約——它保護的不是錢，是不要在活動進行到一半時整站的 AI 功能同時死掉。

02 · 目錄

除了 gemma-4，還有十六個可以選

用這個專案自己的預算假設當基準：一次完整的審議報告，輸入上限 48,000 位元組、輸出 max_tokens 4,096，輸入 token 用「位元組數 + 256」當保守上界。同一份工作換不同模型，免費額度能撐幾次差了六十倍。

幾個值得單獨講的：

granite-4.0-h-micro 是目錄裡最便宜的通用文字模型，同一份報告只要 116 neurons，免費額度可以跑 86 次——是 gemma-4 的 4.7 倍。代價是模型很小，寫不出帶引用的敘事，但拿來做「分類這 24 句屬於哪個主題」這種結構化任務綽綽有餘。

qwen3-30b-a3b-fp8 是中文場景最划算的一檔：30B 的 MoE 但每次只啟用 3B，計價跟 llama-3.2-3b 一樣（348 neurons／次），免費可跑 28.7 次，是 gemma-4 的 1.6 倍。

glm-4.7-flash 有 131,072 token 的上下文窗，對「把整場對話的所有陳述一次餵進去」這種需求是唯一不用切批次的選項——而 Pocket Polis 現在的 categorize 階段正是分批做的。

反直覺的一個：gemma-3-12b-it 比 gemma-4-26b-a4b-it 貴三倍。前一代、參數更少，價格卻更高——因為 gemma-4 是 26B 的 MoE 只啟用 4B。在 Workers AI 上，模型的參數量跟它的價格幾乎沒有關係，只有 neuron 表算數。

為什麼作者選了 gemma-4

不是他挑的，是 Cloudflare 推的。2026 年 5 月 8 日的變更日誌宣布刷新目錄、十八個舊模型在 5 月 30 日下架，官方列出的三個推薦替代就是 glm-4.7-flash、gemma-4-26b-a4b-it 和 kimi-k2.6。三者之中 kimi 需要付費計費方式，glm-4.7-flash 更便宜但沒有視覺，gemma-4 同時有視覺與 tool calling。對一個「一鍵部署、不能假設使用者有付費方案」的專案，gemma-4 幾乎是唯一解。

04 · 改法

三個不用換模型就能拿到的改善

一、保守上界讓自己少了三到四倍餘裕

Pocket Polis 估算 input tokens 的方式是 utf8_bytes(system) + utf8_bytes(user) + 256。這個上界對安全性沒問題，但代價很大：正體中文一個字在 UTF-8 是 3 個位元組，而在多數 tokenizer 裡大約是 1 到 1.5 個 token。也就是說，48,000 位元組的中文提示詞真實大約是 11,000 到 16,000 個 token，而它記帳記成 48,256 個。

同樣的 gemma-4，同樣的免費額度，實際上能跑的次數是帳面的三到四倍。英文更誇張（1 token ≈ 4 字元）。要拿回這些餘裕不用換模型，只要改成用 ai.run 回傳的實際用量結算、或掛 AI Gateway 讀真實 token 數，把保守上界降為預約用、實際用量用來釋放。

二、語意去重便宜到不必猶豫

開放投稿的題庫一定會長出近似重複的陳述，現在只能靠主持人肉眼審。embedding 的價格是另一個量級：bge-m3 和 qwen3-embedding-0.6b 都是 1,075 neurons／百萬 input token，把一場 800 句上限、每句 280 字的對話整批算完，保守上界也只要 700 顆出頭——不到一次 AI 報告的六分之一。

Google 在這一欄也有東西：@cf/google/embeddinggemma-300m，300M 參數、768 維、以 Gemma 3 為底（T5Gemma 初始化），訓練涵蓋 100 種以上語言，Cloudflare 是與 Google 同步的發布夥伴。以正體中文的語意去重來說，它跟 bge-m3 是同一個量級的候選，維度只有 768（bge-m3 與 qwen3-embedding 是 1024），存進 Vectorize 省三分之一空間。

但有一個要注意的落差：embeddinggemma-300m 出現在模型頁與 AI Search 支援清單上，卻沒有出現在 Workers AI 定價頁的 embeddings 表裡（定價頁 2026-08-28 版只列了四款 bge、plamo-embedding-1b 與 qwen3-embedding-0.6b）。掛牌價缺席不代表免費——要用它就先跑一批小量測試，從儀表板讀實際 neuron 消耗再決定，別照著別款 embedding 的價格估算。

而 bge-reranker-base 是 283 neurons／百萬 token，全目錄最便宜的一檔。「這句跟第 7 句很像嗎」用 embedding 粗篩、reranker 精排，兩步加起來的成本仍然是雜訊等級。這件事早就該做了，擋住它的不是預算，是沒人想到 embedding 跟 LLM 差了一個數量級。

三、cached input 是一個沒被用到的槓桿

deepseek-v4-flash 的 cached input 是 1,273 neurons／百萬，正常 input 是 40,000——相差 31 倍。glm-5.3-flash 的 cached 是 2,727 對 13,636，五倍。Pocket Polis 的 synthesis 提示詞每次都以同一份系統指令與同一批陳述開頭，只有結尾的資料在變，正是快取前綴最理想的形狀。

限制是這兩個模型都在付費牆後面。所以這條路對「一鍵部署給別人」的預設情境沒用，但對作者自己那個 polis.mashbean.net 正式站有用——那是他自己的帳號，本來就可以開付費。

如果只能改一件事

改計費估算，不要換模型。gemma-4 在「開放、有視覺、有 tool calling、又是官方推薦替代」這四個條件下沒有更好的選擇；真正在浪費的是那個把中文位元組當 token 記的保守上界。把它從「記帳方式」降級成「預約時的上界」，實際用量事後結算，同一顆模型、同一份免費額度，可用次數立刻乘三。
