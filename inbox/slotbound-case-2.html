STAGE 01 · 洗版 · THE FLOOD

兩個月內的第二次

這種場面今年秋天已經看過一次。9 月 3 日 OpenAI 發表 GPT-6 Astra，接下來那個週末，X 上滿是一句話做出來的 3D 遊戲。最常被轉貼的例子是一位開發者說他 45 分鐘就拿到一款能玩的遊戲，只用掉每週額度的百分之幾。還有人用 24 分鐘把整座杭州搬進網頁。

11 月 9 日 18:58（UTC），Anthropic 發表 Claude Fable 5.2。同一天，Anthropic 自己的員工貼了兩種東西。一種是影片，就是下面會講的恐龍短片。另一種是能玩的遊戲：發表後三分鐘，做產品的 Felix Rieseberg 貼出第一批作品，網頁標題就叫 Three Games，頁尾註明都是初稿，沒有人給過回饋。當天稍晚，他把其中一款射擊遊戲《Saltline》單獨貼出來，附上 token 數和費用，七分鐘後再貼出那句指令。到 11 月 14 日，那則貼文有四百三十多萬次觀看。

接下來的幾天，同樣的事在中文圈重演。有人整理的清單在一週內收了 165 件點得開的作品，其中 82 件是遊戲，另外還有 119 支展示影片。也有人架了專門的網站，把三十多款作品連同指令原文一起陳列。Saltline 上線兩天，簡體中文圈就出現改了名字和文字的中文版，整款遊戲包成一個 HTML 檔在網路硬碟流傳。

恐龍那一支，是另一條路線

這一波常被說成是「官方的恐龍 demo」帶起來的。恐龍短片確實有，也確實是上市當天貼的：18 秒，一群恐龍聚在史前的水塘邊。作者 Jeremy Berman 在 Anthropic 做強化學習研究，他引用官方的發表貼文，補了一句說明，說這是 Fable 寫 Python 去操控 Blender，從零做出來的。兩天內約有 28 萬次觀看。

有兩點跟流傳的說法不一樣。第一，它不在官方的發表頁上，那一頁沒有提到恐龍，所以它是員工的個人貼文，跟 Saltline 一樣。第二，它用的是 Blender，沒有用 three.js。成品是一支算好的影片，不能玩，也沒有即時算圖這回事。指令、花了多久、花了多少錢，他都沒有公布。順帶一提，他跟後面帳單表裡做出上萬美元遊戲的 Matthew Berman 是不同的人。

STAGE 02 · 查核 · IS IT TRUE

「只用 three.js，沒有 3D 物件」是真的嗎

先把話說準。three.js 是一套讓瀏覽器畫 3D 的函式庫。流傳的說法是，這些遊戲除了它以外什麼都沒載入，沒有建模軟體做出來的模型檔，也沒有圖片和音效檔。

這不等於「沒有 3D 物件」。畫面上的貨櫃和機器狗仍然是 3D 模型，差別在來源。它們沒有對應的檔案，全是遊戲啟動時由程式當場算出來的：形狀由函式組出來，表面的鏽和積水由著色器算，聲音由合成器產生。這種做法叫程序化生成，在繪圖領域是幾十年的老技術。至於「即時算圖」，任何 3D 遊戲都是即時算的，不是這一波才有。

先分清楚兩條路線

洗版的作品其實走兩條路，常被混在一起講。

路線模型寫的是成品代表作
Blender操控建模軟體的 Python 腳本一支算好的影片，不能互動恐龍短片、Bugatti 跑車
three.js在瀏覽器裡執行的程式打開網頁就能玩Saltline

兩條路的共同點是素材都由程式寫出來，沒有人動手建模。差別在算圖的時間點。Blender 那條路是事先一格一格算好，所以畫面可以很細，也需要顯示卡花時間去算。three.js 那條路才是邊玩邊算。「只用 three.js」和「即時算圖」講的是後者，恐龍屬於前者。

我自己打開來看了

Rieseberg 說，所有貼圖和模型都是函式，原始碼就在 HTML 裡，誰都可以檢查。有人在討論區提出合理的懷疑：1.4 MB 的單一檔案，從外面看不出裡面是不是藏了一大串編碼過的圖片。所以我把 GitHub 上的公開副本抓下來，用程式掃了一遍。

但它不是每一款都成立，也不是這次才有

同一波裡被歸給 Fable 5.2 的作品，做法差很多：

Abyssal Garden全部由程式生成，而且指令明文禁用 three.js

「不靠素材」也不是 Fable 5.2 才開始的。9 月 Astra 那一波，那位 45 分鐘做出遊戲的開發者事後補充，他的作品同樣只用 three.js、沒有外部素材。當時還有一款火車模擬器標榜沒有匯入任何模型。再往前，6 月 Fable 5 上市時，就有人用 three.js 的基本幾何形狀拼出一架波音 747。

十月還有一個更硬的例子。一位開發者用 Claude Code 搭上一代的 Opus 5.5，做了一片即時算圖的海，連 three.js 都沒用，整個包成一個檔案。它比 Fable 5.2 早三個星期。

同一片海，轉述和說明文件各說各的

這片海值得多看一眼，因為它示範了包裝是怎麼長出來的。把一篇轉述報導和作者自己寫的說明文件並排：

項目轉述報導作者的說明文件
模型Opus 3.5Claude Code 搭 Opus 5.5

人的參與完全由模型生成中途給過回饋，主要在雲。體積雲因此換成平面雲層，後來又修了邊緣的鋸齒

技術本身是真的，而且比轉述寫的更紮實。海浪用的是電影和遊戲業界的正規做法，六層頻譜疊出一公里到幾毫米的波長，海面網格延伸到 160 公里，大氣也照著論文的方法算。每幀 6 到 8 毫秒，換算大約是每秒 125 到 165 幀。

誇大的是外面那一層。時間是轉述加上去的，模型名稱寫錯，人給過的回饋不見了。報導寫的作者名字跟 repo 的帳號也對不上，我無法確認是不是同一個人。這跟 Saltline 的「一句指令」是同一種現象：作品是真的，傳出去的那句話比作品簡單。

還有一點要算進去。這類題目對模型特別有利。海浪和大氣的演算法都有論文和大量公開的實作，目標又只有「越逼真越好」，沒有產品上的限制。作者自己列了侷限：只有開放的海面，沒有海岸，水上也沒有任何物體。要放進遊戲，海得讓船浮起來。遊戲引擎 Phaser 的海面套件做的就是這一段，船尾的浪、船頭的水花、船身隨浪起伏、鏡頭潛到水下，那是另一種工程。

所以這一次真正不一樣的地方有兩個，都跟技術無關。一是有人把帳單貼出來了。二是成品是一個打得開的單一檔案，誰都能檢查，也誰都能改。

為什麼都長得像雨夜的貨櫃碼頭

語言模型的手是程式碼。它不會捏黏土，但會寫函式，所以它擅長的畫面是能用幾何和數學描述的東西：貨櫃、鋼架、無人機、雨和反光。玩過的人回報的毛病也在同一個方向。有人指出小物件互相穿插，樓梯懸在半空，模型乍看合理、停下來細看就不對。也有人一進遊戲滑鼠就失控，根本沒辦法玩。一份整理上市週作品的教學說，最常見的問題是卡頓和操作。

討論區裡最短的一句評語是：這不是遊戲，是技術展示。那句指令本身也只要求一個很小的關卡。

STAGE 03 · 帳單 · THE BILL

一句話要多少錢

約 550 美元

Saltline：一句指令，八小時，一個小關卡。

這個數字的結構比總額有意思。模型寫出來的只有約 270 萬 token，讀進去的卻有 4.45 億，相差一百六十多倍。原因是它每做一步，都要把先前的工作重新讀一遍，然後改一點、跑一次、看結果。八小時就是這個迴圈轉了八小時。

帳單沒有變成天價，靠的是快取。重複讀的內容按快取價計費，每百萬 token 0.2 美元，是正常輸入價 8 美元的四十分之一。有人替他算過，同樣的 token 如果完全不走快取，要三千六百多美元。

同樣叫「一句話做出遊戲」，帳單從 16 美元到一萬四千美元，差了九百多倍。做出上萬美元那兩款的人自己也說，成品還有生硬的動畫和沒修的錯誤。價格跟那句話無關，跟模型跑多久有關。指令是一句，計費單位是小時。

多數人付的是訂閱費，用的是方案裡的額度。額度也有上限。Pro 方案用 Fable 只有一週的試用，而且最多吃掉每週額度的一半，11 月 16 日之後要另外付費。有人回報在每月 200 美元的方案上，一個晚上就用掉 Fable 額度的四分之一。那款 97 KB 的海底世界，模型實際只工作了兩三個小時，卻因為額度限制拖了三天才做完。

Blender 那條路的帳單比較零散。那輛 Bugatti 是一句指令加一張參考圖，跑了大約兩個半小時。有一支 13 個鏡頭的短片公布了算圖費用，租 10 張雲端顯示卡，52 分鐘，5.75 美元。恐龍短片的作者沒有公布自己的數字，只說了一句預測：很快就會有人用 Python 做出整部電腦動畫電影，花費是幾千美元。

對照這個站上先前的紀錄：十月跑三題 three.js 小場景，一共 50 分鐘，大約 15 萬 token。

指令是一句，計費單位是小時。

STAGE 04 · 野心 · WHICH RUNG

這算哪一種野心，第幾階

巧的是，做出 Saltline 的 Rieseberg，就是十月那篇〈How to be more ambitious〉的作者。這個站上讀過那篇，寫成〈記住了第一招，漏掉了第五招〉。拿他自己的尺來量他自己的作品，最公平。

他把野心拆成四種。速度是同一件事花更少時間。高度是往上問目標背後的目標。深度是用頂尖專家的方法把一件事做到極致。廣度是動用別的領域的做法。

野心Saltline 有嗎依據
速度有，而且是主體一個小關卡從幾個月變成八小時
深度確定有一招指令要求 3A 等級的寫實畫面，這是「訂不合理的目標」。至於有沒有外部裁判，他沒有交代用了什麼工具
廣度有一點著色器、音效合成、關卡設計本來是三種人的工作
高度沒有指令是一件任務，後面沒有另一個目標

如果要問它在第幾階，梯子在高度那一節。他用一份季度檢討簡報示範了三階。第一階是讓模型理解整門生意，回答這一季什麼變了、為什麼。第二階是要它找出最急的三個決策。第三階是質疑這場會議為什麼存在，設計更好的做法，再用歷史資料證明。

照這把尺，「做一款射擊遊戲給我」還沒踏上第一階。它是一件任務，做完就做完了，沒有人問這款遊戲要給誰玩、為什麼要有它。洗版的那一百多件作品，野心幾乎都花在速度上，高度是零。

有意思的是，廠商要的正是野心。Aiden's Revenge 的作者說，他拿到提前試用資格時，對方請他拿最有野心的用法來試。他最後做的是外甥畫在紙上的那款遊戲。

這不算批評，Rieseberg 自己就標過限制：高度適合有最終結果要追的事，對創作型的工作效果比較差。他給的判斷方法是，你會不會為這件事開會。沒有人會為一個技術展示開會。

裁判還是不夠

深度的第五招，是不要讓模型評自己，要有模型以外的東西來判。這一波有紀錄可查的做法比以前進步：模型會自己開瀏覽器、截圖、讀錯誤訊息，沒有錯誤才收工。那位照做的作者把流程畫得很清楚，寫程式、開頁面、截圖自檢、讀回錯誤，四步一圈。

十月那片海走得更遠。作者讓模型把截圖交給另外的評審代理來看，說明文件裡寫明，這樣它就不是在替自己打分。即使如此，把體積雲換掉的決定，還是作者自己看了之後下的。

截圖也看不出滑鼠會不會失控，或是樓梯懸在半空。這些是人玩了三十秒才發現的。同一位作者也老實寫了：他的 14 個音效只檢查過有沒有爆音和無聲，沒有人真的聽過。這個站上十月那份試飛報告的標題，在這裡又成立了一次：跑從來不是問題，看才是。

轉貼的人和付帳的人

〈記住了第一招〉裡補過一張表，講人的信心從哪裡來。最強的來源是自己做成過一次，其次才是看別人做成。洗版是後者的工業化：一百六十件作品，幾百萬次觀看，全是看別人做成。

這一波裡走了前一條路的人不多，但看得出差別。那位照做的作者花了折合 47 美元的額度，跑了四個實驗，把指令、腳本和每一筆帳都公開，連哪裡做壞了都列出來。他拿到的東西，跟轉貼影片的人拿到的不是同一種。

傳得最遠的那句話是「一句指令」。沒跟著傳出去的是八小時、4.45 億 token，以及一套能讓模型自己測試的工具。上次漏掉的是第五招，這次漏掉的是帳單。

STAGE 05 · 自己的一次 · MY OWN RUN

我自己付過的那一次

上一節說，看別人做成和自己做成是兩回事。所以這裡要交代我自己的那一次。Astra 那一波之後，10 月 29 日晚上，我也用 GPT-6 Astra 開了一個題目：一架紙飛機，一片沒有邊的海。程式是公開的，打開網頁就能飛。

提交紀錄留下了那一晚的樣子。第一次提交在台北時間晚上 9:28，只有一片海和一架飛機。到半夜 12 點多，一共提交了 9 次，多了配樂和島嶼，也有了手機體感和五個章節。接下來那一件讓它自己跑，提交時間是早上 7:08。之後斷斷續續又做了三天，加了森林和窗景兩個分支，前後共 25 次提交。

拿它對照前面幾節，有三件事對得上。

「只用 three.js」撐不了多久

海和天空可以全用程式算，這跟 Saltline 是同一條路。但一想要別的東西，就得借。海面的寫法參考了前面那片十月的海，也就是 Noniv 公開的 web-ocean。雲用的雜訊核心來自 Ashima Arts 和 Stefan Gustavson 的開源程式。想要一片森林，用的是 Victor Zakharov 的算圖函式庫。想要窗外真的有風景，用的是 Poly Haven 和 Matthew Petroff 的照片。

一個 repo 裡，STAGE 02 那張表上的幾種素材來源全出現了。「不靠素材」是一個題目剛好適合時的結果，不是一種能一路用下去的做法。

借和抄，差在帳上有沒有寫

上篇的山寨是把別人的東西搬走，換個名字，什麼都不說。這裡每一樣借來的東西都留了紀錄：授權條款原文放在 repo 裡，函式庫鎖定在特定版本而且沒有改動，每張照片有來源和授權的清單。模型做得到這件事，前提是有人要求。

不過我自己也漏了一筆。參考 web-ocean 這件事，repo 裡沒有寫。而且我借的只有做法。原因很實際：原版要 WebGPU 和夠力的顯示卡，在我手上的裝置跑不動。沒辦法直接拿來用，只能請 Astra 照那個方向，用 WebGL 2 重寫一個跑得動的版本。它用的是正規的頻譜模擬，我的只是視覺上的近似，說明文件也寫了這一點。

這一筆有個細節值得記下來。那片海是 Claude 做的，公開十二天後，被我用 Astra 借去。一家模型做出來的東西，另一家的模型馬上就能接著用。這跟上篇那位開發者的處境是同一個問題的兩面：別人的做法太容易拿來用，記帳就變成唯一的界線。

要人看的那一眼

提交訊息裡留著問題是怎麼被發現的。「打散海面的格子紋」「把天空留在畫面裡」「設定之後恢復手動飛行」，這幾條修的都是畫面上看得到、測試卻不會報錯的毛病。測試能確認著色器沒有報錯、畫面有在動。海面看起來像不像海，要人打開來飛一下才知道。

說明文件倒是寫得很老實：海浪只是視覺上的近似，模擬測試不等於實機驗收，60 幀的目標還沒驗過。這些句子比畫面更有用，因為它們標出了哪裡還沒有人看過。

能驗野心，不能拿來賣

所以這個作品的用途很清楚。它可以拿來驗自己的野心：一晚能做到哪裡、早上該看什麼，這兩件事我是自己量過的。這次看 Fable 5.2 的洗版，判斷那些影片該信幾分，用的就是那幾個晚上的經驗。

但它不能拿來賣。海面的做法是借的，畫面只是近似，換一台裝置能不能順跑還沒驗過，也沒有任何人在等它。上篇的 Slotbound 賣得動，靠的是上市前就在等的那十萬人。這裡一個都沒有。

至於階梯，它同樣沒有踏上第一階。它是一個讓人發呆用的東西，沒有更上層的目標。

STAGE 06 · 接回上篇 · BACK TO THE CASE

做變便宜之後，剩下什麼貴

上篇的結論是，玩法好改也就好抄，最後擋住山寨的是有一群人認得你。這一篇把同一件事往前推了一格，連我自己那一次也算在內。

Slotbound 被搬上手機花了別人兩個月。Saltline 被改成中文版只花了兩天，因為它本來就是一個打得開的檔案，作者還請大家自己檢查原始碼。能檢查就能改。單一 HTML 檔是目前最容易驗證的遊戲形式，也是最容易被拿走的。

上篇那款完整的遊戲，花了一個人十三個月。這一篇的小關卡，是 550 美元，照做的人是 16 美元。兩者不是同一種東西，但方向很清楚：能動的東西會多到看不完。討論區裡有人說得很白：他想看的是第一款能在 Steam 上賺到錢的。到目前為止，我查不到這一波有哪一款賣了錢。

起點那則心得說，這陣浪潮讓他想到付費手機遊戲剛興起、還有空間的那幾年，很短，但確實有過。兩篇查下來，那個空間現在長這樣：

  • 做，便宜了。一句話加幾小時的額度，就有一個能動的東西。
  • 看，還是貴的。模型測得出有沒有錯誤，測不出好不好玩。要有人玩，而且要玩得夠久。
  • 被認得，最貴。Slotbound 在上市前就有十萬人在等。這件事沒有任何一句指令做得出來。

所以回答「這也是野心嗎」。是，但它是最便宜的那一種。便宜到一個人可以花幾個晚上，只為了知道自己做不做得到。能拿來驗野心的東西，離能拿來賣的東西還很遠。速度的野心已經內建在模型裡，按一下就有。往上的那幾階，要先回答這款遊戲為什麼該存在，而這個問題從頭到尾都是人的。

這一篇證明不了的事

Saltline 的時間、token 和費用都是作者自己公布的約略數字，沒有公開紀錄可以核對，他本人是模型廠商的員工。我檢查的是第三方轉存的副本。這篇的查核和初稿也用了 Fable 5.2，等於請當事的模型查自己的上市潮，讀的時候請把這一點算進去。各家的美元數字多半是照 API 價回推的估算，不是實際付出的錢。恐龍短片沒有公布指令、時間和費用，它有沒有經過人手修改也不知道。這一波作品有沒有任何一款賺到錢，也沒有資料。
