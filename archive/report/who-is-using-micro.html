月租沒變，單價在改

2026 年 11 月 20 日有一張圖在流傳：Claude 的 100 美元月費，用滿可以抵 API 牌價 4,640 美元的量。同一個方案，10 月有人量到 5,725 美元。月費一直是 100 美元。訂閱的月費印在價目表上，單價藏在額度裡。額度多大沒有公布，而且一直在改。

先講清楚的四件事

本文由 Claude（Anthropic 開發的 AI）撰寫。文中比較四家廠商，Anthropic 是其中一家，而且它的倍數最高。本文只排量測數字與各家公告，中立性仍應打折閱讀。

每個數字後面的編號連到文末出處，並標來源等級。排序沿用〈沒有匯率〉：揭露 ＞ 調查 ＞ 分析師 ＞ 轉述 ＞ 部落格。

另外有三種章。推算是別人估的，有假設。自算是本文拿別人的數字做的加減乘除。未驗是查不到出處，或沒有人實測。蓋了章的數字不能當事實引用，全部列在項 09。

這是第三版。第一版的標題問「誰把額度用滿」，那個問題本文的材料答不了。第二版起只主張一件事：訂閱的實際單價由廠商單方面決定，而且事前看不到。第三版對著番外一重寫了項 08。改了哪些地方列在文末。

項 01 · 怎麼量

把額度表從零打到滿，再照牌價算

那張圖是 Paweł Huryn 做的，標題是「訂閱比 API 多買到多少用量」。[1] 他的做法寫在公開的 repo 裡。[2]

  • 讀每家 client 自己回報的週額度百分比。Claude Code 是 rate_limit_event 裡的 seven_day.utilization，Codex 是 rate_limits.primary.used_percent。
  • 量測期間的每一次模型呼叫，從 client 的 log 撈出來，照實際提供服務的模型的 API 牌價計價。client 自己印的費用欄位不採用。
  • 算出額度表每走 1% 值多少美元，乘以 100 是一週，再乘以 30.4375 ÷ 7 是一個月，最後除以月費。

所以「46.4 倍」的意思是，把 100 美元方案一個月的額度全部用完，同樣的呼叫改走 API，帳單是 4,640 美元。

Huryn 自己列了四個限制。[2] 倍數假設整週都能用滿，但 Claude 另有 5 小時窗，可能先卡住。結果跟工作內容有關：同樣是 Claude，短的平行 session 約六成是 5 分鐘 cache 寫入，量到 45 倍上下；長的歷史 session 有 78% 是 cache 讀取，量到 62 倍上下。10 月那一輪多數方案只跑一次。計價用的是 API 牌價，是 API 使用者會付的錢，跟廠商的成本無關。

判讀

這個數字可以重做，方法和 10 月的資料都公開。它量的是某一天的天花板。六列的量測日、模型與設定都不同，橫向排名要保留。額度多大要靠外面的人這樣量，這件事本身就是下面幾項的起點。

SemiAnalysis 兩份報告都在付費牆後，本文讀到的是其他媒體的轉述。6 月那兩列是「最高可到」，10 月那幾列是一般估計，兩種數字不能直接相除。Wokey 那一列的量測週剛好跨過 10 月 29 日。最後一列是影片的文字摘要，原始量測方法不明。Huryn 11 月 19 日的貼文仍寫 OpenAI 約 10.5 倍，並預告 Gemini 初估 25.2 到 26.2 倍。[4]

數字不一樣，原因查得到三個。

第一個是 cache 比例。項 01 提過，同一個方案從 45 倍到 62 倍，差別只在讀取和寫入各占多少。Wokey 用 92% cache 讀取的比例估出 34 倍，SemiAnalysis 用它自己的 agentic 工作負載估出 58 倍，兩個都說得通。

第二個是日期。項 05 會排出來，四家的額度在這一年半裡一直在動。同一個 ChatGPT Pro，6 月、10 月初、10 月底是三個不同的東西。

第三個是「5x」「20x」指的窗不同。Claude 的 200 美元方案過去叫 Max 20x，20 倍指的是 5 小時窗。SemiAnalysis 量到它的週額度是 Pro 的 10.0 倍自算，Wokey 量到 9.7 倍，[7][10] 官方的價目頁現在也直接寫每週是 Pro 的 10 倍。[16][18]

判讀

Claude 的個人方案用滿，幾把尺落在 34 到 59 倍。ChatGPT 在 10 月初是 10 倍上下，10 月 29 日加倍之後還沒有人用同一套方法重量，圖上那一列 10.25 倍是加倍之前的數字。這段時間兩家的月費都沒有動。倍數會動是因為額度在動，而額度多大只能靠外面的人量。

項 03 · 帳單抬頭

同一個工具，三種單價

先看 Anthropic 自己的價目頁。[16]

  • Max，每月 100 美元。用量是 Pro 的 5 倍，每 5 小時與每週各算一次。Fable 最多用到週額度的 50%。附每月 100 美元的 API credits。
  • Team，標準席年繳每月 20 美元、月繳 25 美元，用量「比 Pro 多」。Premium 席年繳 100、月繳 125，是標準席的 5 倍。全隊共用的 API credits 每月最多 500 美元。
  • Enterprise，每席每月 20 美元，年繳，最少 20 席。用量照 API 牌價計。

Team 的「比 Pro 多」是多多少，價目頁沒寫。幾份整理 Help Center 的第三方文章寫的是每個 session 1.25 倍，Premium 席 6.25 倍，每席各算，不能互轉。[19] 照這個數字除一下月費：Pro 是 1 ÷ 20，Max 是 5 ÷ 100，Team 月繳的兩種席是 1.25 ÷ 25 和 6.25 ÷ 125，四個答案都是 0.05。自算 月繳的 Team 席，每一美元買到的 session 額度跟個人方案一樣，年繳便宜兩成。

但 session 額度只是其中一道上限。Team 的週額度沒有公布，本文也沒有找到任何人照項 01 的方法量過 Team 席。「Team 也是四十幾倍」只能是推算。未驗

Enterprise 這一格不用量。Anthropic 的說法是 Claude、Claude Code 與 Cowork 的用量全部另外照標準 API 費率計，沒有每席上限，也沒有附送的 token。[20][19] 花 100 美元的用量就是 100 美元。加上 20 美元座位費，是花 120 拿 100，0.83 倍。自算 舊合約的 seat-based Enterprise 在續約前保留每席額度，計費方式跟 Team 一樣。[19][17]

公司實際面對的選擇在中間與右邊。Team 最多 150 席，[59] 超過就只有 Enterprise。150 席以內的公司要在 Team 與 Enterprise 之間選，而 Team 這一格沒有人量過。這張帳單上最該有數字的地方是空的。

按量付費的人實際花多少

Anthropic 的文件有一段平均數：企業部署裡，每位開發者每個活躍日的成本約 13 美元，每月 150 到 250 美元，九成使用者每個活躍日低於 30 美元。[17]

把這幾個數字放在一起算。自算

  • 平均的開發者在 Enterprise 上連座位費是每月 170 到 270 美元，是 Max 月費的 1.7 到 2.7 倍。
  • 九成的人每月不到 660 美元，占 Max 天花板的 11% 到 14%。
  • 照 API 計價的用量超過每月 80 美元，大約 6 個平均的活躍日，100 美元的 Max 就比 Enterprise 便宜。

這幾行有一個限制。這群人是按量付費的，按量付費的人會省著用，換成吃到飽之後用量多半會變。所以它只能回答一個問題：照他們現在的用量，帳單印哪一種抬頭比較便宜。它不能拿來推估訂閱者實際用掉多少。

其他三家的公司價

OpenAI 的 Business 標準席年繳每月 20 美元，Work 與 Codex 的額度跟 Plus 同級。Premium 席年繳 100 美元，是標準席的 5 倍，沒有 5 小時限制。[53][34] Enterprise 與 Edu 改用 credits，沒有固定的用量上限，credits 對 API 牌價怎麼換算，本文沒有查到公開數字。[34] Google 的企業版沒有公布用量限制。[52] xAI 沒有查到對應的公司方案。

判讀

同一個工具、同一個模型，單價跟著帳單抬頭換。個人與 Team 的單價要看你用掉額度的幾成，額度多大又沒有公布，所以訂閱的單價事前算不出來。Enterprise 的單價算得出來，就是牌價。多付的錢買到的是可預期、沒有上限，以及 SCIM、稽核紀錄這類管理功能。[58]

項 04 · 誰在用

廠商為什麼一直調：線索有四條，都不夠硬

額度為什麼要一直改，最直接的解釋是用量集中在少數人身上。這一節的證據是全篇最弱的，先把四條線索和各自的毛病列出來。

  • Anthropic 自己講過兩次。2025 年 7 月加週上限時，它估受影響的訂閱者不到 5%，理由是帳號共用、轉售，以及有人把 Claude 放在背景 24 小時跑。[22][23] 它還舉了一個例子：有人訂 200 美元的方案，用掉數萬美元的量。[24] 2026 年 3 月尖峰時段加扣時，它估約 7% 的使用者會撞到原本撞不到的上限。[30] 毛病：兩個數字都是當時的上限、當時的訂閱者，一個是一年多前的。
  • 買高價方案的比例。a16z 第七版的消費者 AI 榜引用 YipitData 的美國面板資料。Claude 的付費者裡，7.3% 訂了最貴的個人方案 Max，100 美元起跳。Google 對應的比例是 1.3%，ChatGPT 是 1.1%。[21] 毛病：這是誰付比較多錢，不是誰用比較多。
  • 分析師的估計。SemiAnalysis 10 月的報告說，訂閱只占 Anthropic 整體營收約一成，卻可能吃掉四成以上的推論算力。[6]推算 照這兩個比例換算，每一美元訂閱營收占用的算力是其他營收的 6 倍。自算 毛病：只有一家這樣估，細節在付費牆後。6 倍可以是少數人拉高的，也可以是人人都用到那個水準，單看這個數字分不出來。
  • 貼出來的帳單。有人在 100 美元的 Max 上 21 天用掉 2,976 美元。[56] 有人在 200 美元的 ChatGPT Pro 上 19 天跑了 5,961 美元，只算沒有走 cache 的輸入輸出是 2,045 美元。[55] Huryn 較早的一篇寫的是一個月 1,588 美元，用 200 美元的方案付掉，約 8 倍。[57] 毛病：願意貼帳單的人本來就偏重度。

項 03 那組企業平均數不能算第五條。那群人按量付費，用量受價格約束。

四條放在一起，「重度使用者是少數、但占掉可觀的算力」是合理的猜測，本文沒有證明。訂閱者實際用量的分布，四家都沒有公布過。

判讀

誰把額度用滿，這篇答不出來。能說的只有：廠商自己講過重度使用是少數，分析師估這少數占掉不小的算力。下一項的紀錄有收也有放，收的時候是在壓這群人的成本，放的時候是在搶同一群人。把額度看成廠商手上可以調的變數，比看成專門對付誰的工具，更符合紀錄。

判讀

四家沒有一家的額度穩定超過幾個月，而且收和放的次數差不多。Anthropic 改最多次，兩個方向都改過。OpenAI 先放、再收、被罵之後退回一半，是四家裡唯一公開把調降收回去的。Google 換了計量單位，幾天內又把額度調高到調降後的 9 倍。xAI 併池不到三週就砍。月費沒變，變的都是月費買到的量。

四家都只給倍數，不給數字。

判讀

四家沒有走同一條路。共同的只有兩件事：都有週上限，都不說它多大。價目頁上寫的是「Pro 的 5 倍」「Plus 的 20 倍」這種相對值，基準是多少沒有人講，所以外面才需要有人拿額度表去量。規則各家自己訂，寫在更新紀錄裡，訂閱者事前看不到數字，事後也只看得到百分比。

項 07 · 不是匯率

連倍數的分子，也是廠商訂的

接回〈沒有匯率〉

倍數的分子是 API 牌價。牌價是廠商自己訂的，三家差很多。每百萬 token 的輸入與輸出，GPT-6.1 Sol 是 2 與 10 美元，Opus 5.5 是 4 與 20，Fable 5.2 是 8 與 40。[34][51][52]

起點那張圖上就有一個例子。Fable 的牌價是 Opus 的兩倍。同一份週額度，如果額度表只數 token，換成美元應該變兩倍。如果額度表照牌價扣，換成美元應該一樣。圖上兩種都不是：Opus 是 46.4 倍，Fable 是 27.3 倍，少了四成。[1] 照這個比例，同一份額度能跑的 Fable token 大約是 Opus 的三成。自算 這個換算假設兩次量測的 cache 比例相近。額度表對每個模型怎麼扣，Anthropic 沒有公布，另外還有 Fable 最多用到週額度一半的上限。[16]

第二個例子只能當例子看。Huryn 另外做了一個修 bug 的測試：兩個 repo，埋 105 個 bug，讓模型自己找、自己修，記錄修到幾個、花多少 API 費用。[5]

判讀

倍數是三個數字算出來的：月費、額度、牌價。三個都是廠商訂的，只有額度不公布，額度表對不同模型怎麼扣也不公布。跨廠商比倍數，比到的有一大塊是各家的定價方式。〈沒有匯率〉說 token 成本和完成的工作之間缺一頁換算表，這裡是同一個缺口。

項 08 · 接回番外一

兩篇接得上的地方，都在帳號

番外一〈貨到哪，票開給誰，誰在用〉讀的是晶片與模型的三個地址。這一篇讀的是訂閱的帳。兩篇問的「誰」不在同一條軸上：那一篇問國籍與控制權，這一篇問用量輕重，以及帳號後面是不是同一個人。接得上的地方有三個。

一、個人訂閱報帳

番外一欄 06 引過 7 月的一則報導：字節讓工程師報帳個人訂閱，再用 VPN 連線。[60] 那一篇把它當成繞過公司那扇門的路。照這一篇項 03 的算法，個人訂閱剛好也是三種抬頭裡單價最低的一格。同一個做法，一邊繞資格，一邊省錢。帳單印的是個人，用的是公司，這就是「票開給誰」和「誰在用」對不上，只是發生在訂閱這一層。字節這樣做是為了哪一個，報導沒有說。

項 10 · 現在能說什麼

三種把握，分開放

有出處就能說的

  • Claude 的個人訂閱把額度用滿，照 API 牌價值月費的數十倍。三組獨立量測落在 34 到 59 倍。
  • Claude Enterprise 的用量照 API 牌價，另收座位費。
  • 2025 年 8 月到 2026 年 11 月，四家都動過額度，有收有放。四家都有週上限，都不公布它多大。
  • Anthropic 與 Google 都擋過用訂閱登入第三方工具的帳號。OpenAI 承認個人這樣用。
  • OpenAI 在 10 月 29 日取消對 Pro 200 的調降，並把另外兩級與 Business Premium 加倍。
  • Musk 公開說，砍 Grok Bot 的額度是因為成本相對營收太高。

帶著假設才能說的

  • 訂閱的實際單價由廠商單方面決定。依據是額度不公布，以及一年半 26 次的改動紀錄。
  • 重度使用者是少數，但占掉不小的算力。依據是 Anthropic 兩次的說法與 SemiAnalysis 一家的估計。
  • Team 席每一美元買到的額度跟個人方案相近。依據是第三方整理的 session 倍數，沒有實測。
  • 額度表對貴的模型扣得比牌價比例更重。依據是圖上 Opus 與 Fable 兩列。

現在還不能說的

  • 訂閱者實際用量的分布，也就是誰把額度用滿。
  • 廠商在訂閱上賠多少。牌價不是成本。
  • 按完成的工作算，哪一家的 100 美元方案比較划算。
  • Enterprise 議價之後的實際單價。
  • Team 席與 OpenAI Business 席的倍數。
  • xAI 砍完之後的新額度，以及 OpenAI 12 月併池後的池子大小。
  • Google 的倍數怎麼走。目前只有 Huryn 一個點。
  • 1 月與 2 月被停權的帳號有多少。
  • Anthropic 的帳號驗證和地區政策是不是同一套做法。

會改變判斷的訊號

  • 任何一家公布額度的絕對值。這篇的主張就要重寫。
  • 有人在 10 月 29 日之後，用同一套方法重量 ChatGPT Pro。
  • 有人照同一套方法量 Team 席或 Business 席。
  • OpenAI 12 月有沒有公布共用池的大小。
  • xAI 有沒有更新用量頁，寫出新的池子。
  • 任何一家再調 API 牌價。倍數會跟著動，額度不一定。
  • Anthropic 或 OpenAI 的公開財務文件有沒有拆出訂閱的營收占比與毛利。

資料與時效

資料截至 2026 年 11 月 20 日。起點那張圖的 X 貼文本文打不開，六列數字讀自讀者轉來的圖檔。Huryn 的 repo 說明仍是 10 月那一輪，11 月的新數字本文沒有對到原始檔。SemiAnalysis 的兩份報告在付費牆後，金額取自其他媒體的轉述。OpenAI 的 Help Center 只讀到搜尋摘要與媒體引述。Anthropic 的價目頁與 Claude Code 文件是直接讀的。額度每幾週就動一次，本文的任何倍數過一個月都可能不成立。
