25H2 之後 YouTube 變卡：從現象到根因

整理日期：2026-08-23　對象：正式版 25H2（組建 26200.xxxx），不是 26H1／尚未全面上市的 26H2。

1. 範圍與先看這張表

「YouTube 變卡」在 25H2 上很少是網站本身壞掉。比較常見是：視訊硬解 + 視窗合成（DWM / MPO）+ 瀏覽器 GPU 程序 三者對不齊。遊戲可能仍順，本機播放器可能也順，只有 Chrome／Edge 卡。

先問若「是」優先懷疑
關瀏覽器硬體加速後能播完？能播、CPU 變高GPU 硬解／overlay，不是網路
Firefox 或「影片與電視」順、Chrome/Edge 卡？是Chromium ↔ 驅動／MPO
chrome://gpu 幾乎全 Software only？是GPU 程序起不來或被封鎖（常見於 Arc OEM 舊驅動）
多螢幕、混 60Hz／59.94Hz、HDR？是MPO／翻頁同步
Copilot+ 筆電、Recall 開著、記憶體完整性開著？是NPU／VBS 背景負載（次要，但 140V 這類機要查）
只有全螢幕 HDR、滑鼠一移到頂就頓？是YouTube UI 疊到 MPO 視訊平面（AMD 工程師有回報，Arc 可重現）
2026 年 8 月現況：一般電腦重裝官方 ISO 得到的是 25H2。26H1 只給特定新 ARM 機；26H2 仍是秋季 enablement 預告／Insider。重裝不會 magically 換成 26H1。

2. 現象分類

  • 畫面一頓一頓、音訊還在走：合成／翻頁掉幀，不一定是解碼失敗。
  • 轉圈、reload 兩三次後整頁卡死：硬解初始化失敗，播放器重試（Arc + Chrome 實見過）。
  • 滾動頁面時瀏覽器假死 10–30 秒：Chromium + 影片 overlay + 有時再加 OBS／Discord 擷取。
  • 低解析卡、4K 反而順：部分 NVIDIA 路徑對低解析＋強化／升頻處理異常。
  • 60Hz 螢幕卡、高刷新順：HAGS + 固定 60Hz 媒體路徑（NVIDIA 論壇常見）。
  • 滑鼠在網頁上移動伴隨音訊短卡／滋一聲：AMD RX 6000 + 較新 Adrenalin + MPO。
  • 設定裡加速是開的，gpu 頁卻全 Software：GPU process 崩潰或 blocklist，不是「沒開加速」。

3. 25H2 共用根因（與顯示卡品牌無關）

3.1 DWM 與 MPO（最常被點名）

Windows 用 Multi-Plane Overlay 把「影片那一層」直接送到顯示器，減少拷貝。25H2／24H2 後期對 overlay、無邊框視窗、HDR、多螢幕的切層行為有改。YouTube 的進度條、全螢幕退出鈕會突然多一層，驅動若接不好就掉 flip → 頓一下或卡死。

Chromium 議題 YouTube HDR Video Lag in Fullscreen when UI is Brought Up 由 AMD 工程師開單，環境含 Win11 25H2；Arc B570 可重現，部分舊 NVIDIA 因根本沒進同一種 MPO 狀態而沒中。

3.2 硬體加速 GPU 排程（HAGS）

把排程從 OS 丟進驅動。遊戲＋幀生成常需要它；媒體在 60Hz、多螢幕上有人必須關才能消 judder。

3.3 瀏覽器硬解 vs 軟解

VP9／AV1 走 GPU 時，失敗不會永遠黑屏，而會「重載 → 再試 → 卡死」。關硬體加速等於逼走 CPU，當作對照實驗，不是長期最佳解。

3.4 多螢幕與混刷新率

60Hz + 59.94Hz、筆電面板 + 外接 144Hz，Arc B580 社群有 YouTube／DAZN 卡死、單螢幕或關加速就好的紀錄。

4. Intel Arc / Xe

4.1 為什麼 25H2 + Arc 特別容易爆在瀏覽器

  • Arc 的瀏覽器路徑高度依賴 D3D11／硬解 + overlay，不是「遊戲驅動好就等於 YouTube 好」。
  • 筆電 Arc 140V／130V（Lunar Lake） 常被 OEM 鎖在舊版（實例：32.0.101.6737，約 2025 年 4 月）。Intel 通用包 2026 年 8 月已到 32.0.101.8974，且支援 140V，但裝置管理員會說「最佳驅動已安裝」。
  • pnputil「已新增 1」只代表進了驅動存放區，不代表裝置已改綁。不從清單手動選新版，畫面仍會顯示 6737。
  • Chrome 2026 已拿掉 ANGLE D3D9。D3D11 起不來就整顆變 Software／WARP，不能再靠「選 D3D9」急救。

4.2 典型因果鏈（140V 實測路徑）

  1. 25H2 + OEM 6737 → Chromium 硬解／合成不穩。
  2. 設定 OverlayMinFPS、關 overlay flag → 可能更糟或沒幫助。
  3. chrome://gpu、edge://gpu 變成幾乎全 Software；YouTube reload 數次後卡死。
  4. 官網 Installer.exe 閃退：log 顯示已有 .NET 9／10，但安裝程式再裝 .NET 10 得到 MSI 1603，結束碼 2147516563。驅動檔其實是完整的。
  5. 手動 iigd_dch.inf 可加入存放區，Windows 仍偏好 OEM 6737。

4.3 Intel 解法（由輕到重）

  1. 對照：Edge／Chrome 關硬體加速；Firefox、系統播放器測同一支影片。
  2. 設定 → 系統 → 顯示器 → 圖形：瀏覽器指定高效能（Arc），不要「讓 Windows 決定」。
  3. 下載 Intel 通用包（Download 785597，gfx_win_101.8974.exe），解到例如 C:\IntelDrv。
  4. 修 .NET Desktop Runtime 10（應用程式 → 修改 → 修復）+ lodctr /r 後再跑 Installer.exe。
  5. 或略過精靈，管理員 CMD 自行輸入： 
    cd /d C:\IntelDrv\Graphics
pnputil /add-driver iigd_dch.inf /install
    路徑不要從網頁複製（可能含隱藏字元 U+202A，會報套件無效）。140V 用 iigd_dch.inf，不要用獨立顯卡的 iigd_dch_d.inf。
  6. 裝置管理員 → 更新驅動程式 → 從清單挑選 8974。必要時 pnputil /enum-drivers 刪 6737 的 oemXX.inf，斷網再掃描。
  7. 仍不穩再考慮 DDU 安全模式；正常模式也可以先覆蓋安裝。
筆電不要以為「重裝 Win11」會跳到 26H1。官方媒體是 25H2，原廠還原常把 6737 裝回來。

5. NVIDIA

5.1 常見根因

  • MPO + 瀏覽器／Discord／OBS／Overlay：官方有說明與 mpo_disable.reg（OverlayTestMode=5）。25H2 上有人反映還要搭配 OverlayMinFPS=0。
  • HAGS 開著 + 60Hz 媒體 judder：關 HAGS 影片好、但幀生成遊戲會抱怨。多螢幕更明顯。
  • Optimus 筆電指錯 GPU：Chrome 走獨顯或走內顯不一致；有人改走 iGPU 串流反而穩。
  • RTX Video Super Resolution／HDR／低解析強化：低畫質片卡、4K 反而不卡。
  • 滾動有影片的頁面時整個 Chromium 假死；NVIDIA 關閉 MPO 後 Brave／Firefox 都恢復的案例存在。

5.2 NVIDIA 解法

  1. NVIDIA App／官網最新 Game Ready，清潔安裝。
  2. 控制台：電源管理 → 最高效能；瀏覽器指定 GPU。
  3. 關 RTX Video 增強做 A/B。
  4. 官方停用 MPO 登錄檔，或手動： 
    reg add "HKLM\SOFTWARE\Microsoft\Windows\Dwm" /v OverlayTestMode /t REG_DWORD /d 5 /f
reg add "HKLM\SOFTWARE\Microsoft\Windows\Dwm" /v OverlayMinFPS /t REG_DWORD /d 0 /f
    然後重開。要還原就刪這兩個 DWORD。
  5. HAGS：設定 → 系統 → 顯示器 → 圖形 → 預設值。只對「60Hz 媒體卡、遊戲還要幀生成」的人需要權衡。
  6. 瀏覽器關硬體加速僅作確認，不是終解。

6. AMD

6.1 常見根因

  • Adrenalin 26.2.2 之後，RX 6000 系列在 Chromium 上出現游標微頓 + 背景 YouTube／音樂音訊毛刺；26.1.1 或 Windows Update 舊驅動反而沒事。關 MPO 可消。
  • 25H2 HDR 全螢幕 YouTube，滑鼠移到頂端出現退出鈕時掉 flip（AMD 開的 Chromium 單）。
  • FreeSync + 多螢幕 + 瀏覽器 overlay。
  • Adrenalin 自動更新、Windows 再塞一版，版本混亂。

6.2 AMD 解法

  1. Adrenalin 用 Cleanup Utility／安全模式清乾淨再裝目標版；關掉自動更新。
  2. 同一套 MPO 登錄（OverlayTestMode=5，必要時 OverlayMinFPS=0）。
  3. 暫時關 FreeSync 對照。
  4. HDR 全螢幕頓：先視窗播放，或等瀏覽器／驅動修 MPO 切層。
  5. 晶片組驅動與 GPU 驅動分開更新，避免只更其一。

7. Windows AI／Copilot+ 的可能性

多數「YouTube 變卡」主因仍是 MPO／驅動，不是 Copilot 聊天視窗。但 Lunar Lake Arc 140V 這類機常常是 Copilot+ ，AI 功能不是零成本。

功能可能怎麼干擾影片怎麼驗證／關
Recall（回顧） 畫面有變化就近乎每 5 秒快照，吃磁碟、NPU、有時 GPU 合成 設定搜尋 Recall → 關閉。非 Copilot+ 根本沒有
VBS／記憶體完整性 Recall 等功能要求 HVCI；部分機遊戲／媒體微頓增加 Windows 安全性 → 裝置安全性 → 核心隔離。關了較不安全，只作對照
Click to Do、設定裡的 Agent、AI Actions 額外處理程序；通常不是 YouTube 主兇 設定相關開關；不建議用來路不明「一鍵刪光 AI」腳本當第一手段
Auto Super Resolution／視訊超解析 把 1080p 往上拉，增加延遲或不穩 系統 → 顯示器 → 圖形 → 自動超解析；NVIDIA 則關 RTX VSR
Game Bar／擷取／Xbox 疊層 與 MPO、瀏覽器 overlay 疊加，25H2 遊戲卡頓文也常點名 Win+G 關掉背景擷取；設定 → 遊戲 → Xbox Game Bar
Windows Studio Effects（視訊鏡頭美顏） 佔 NPU／GPU，通常影響會議不影響 YouTube；雙開時可能搶資源 相機設定關閉效果後再測
Copilot 側邊／Edge 工作區 多一個 GPU 合成視窗 關 Edge 側邊 Copilot 對照
AI 項目建議當「排除項」：先關 Recall 與 Game Bar 擷取 5 分鐘測 YouTube。若完全沒差，回頭處理驅動／MPO，不要在 AI 開關上打轉。

8. 瀏覽器與 2026 Chromium

  • Chrome／Edge／Brave 同一條硬解 + DirectComposition overlay。一邊壞通常兩邊壞。
  • 2026 年 Chrome 移除 ANGLE D3D9，失敗改掉 WARP／軟體，不再有「改 D3D9 治模糊／卡頓」這條路。
  • 設定開加速、gpu 頁卻 Software：代表 GPU process 掛了或 blocklist，不是開關沒開。
  • 實驗旗標（ignore-gpu-blocklist、關 Skia Graphite、關 direct-composition video overlays）只能當手術刀。堆一堆 flag 會讓狀態無法解釋。
  • 清 %LOCALAPPDATA%\Google\Chrome\User Data\GPUCache（Edge 對應 User Data）可排除壞掉的 shader 快取。

9. 診斷流程（建議順序）

  1. winver 確認 25H2／26200，不要和 26H1、Insider 26H2 搞混。
  2. 同一支影片：Chrome、Edge、Firefox、本機播放器。記下誰卡。
  3. 只關瀏覽器硬體加速重測。能播 = 網路沒問題。
  4. 開 chrome://gpu／edge://gpu：看 Graphics Feature Status、GL_RENDERER、Problems Detected。應看到真實 GPU 名，不要是 Basic Render／WARP。
  5. 單螢幕、關 HDR、刷新率對齊後再測（排除混 Hz）。
  6. 工作管理員看解碼是否在 GPU Video Decode，以及有無 Recall／Game Bar。
  7. 裝置管理員看驅動版本日期；筆電對照 OEM 與 Intel／NVIDIA／AMD 官網最新版。

下列為同一條除錯鏈，避免以後重走。
